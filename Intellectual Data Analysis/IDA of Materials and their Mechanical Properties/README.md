# IDA of Materials and their Mechanical Properties

Machine learning (ML) models were trained using the [Materials and their Mechanical Properties](https://www.kaggle.com/datasets/purushottamnawale/materials) dataset obtained from the Autodesk Material Library.

Following standard data cleaning and exploratory data analysis (EDA), a train-test split was performed. The primary objective of training the ML models is to determine material quality based on mechanical properties.

For training purposes, the following ML models were trained:
- Decision Tree;
- K Nearest Neighbors (KNN);
- Support Vector Machine (SVM);
- Random Forest (RF);
