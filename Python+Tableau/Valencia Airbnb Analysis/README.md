Customer's Task:

"I would like to purchase a property in Valencia, Spain, to rent it out. It`s should be possible to determine whether it would be worthwhile to pay extra for a property with more rooms, or whether the additional cost would not be justified. I would also like to find out how much rooms are rented for in different parts of the city. Additionally, i would like to analyse the number of bookings per host to understand how many bookings I can expect as a potential host".

To find required data we could use the [Inside Airbnb](https://insideairbnb.com/get-the-data/) dataset for Valencia, Spain. Than this dataset was cleaned and prepared using Python and pandas library. Subsequently, the results were visualized using [Tableau](https://public.tableau.com/views/valencia_17883012197650/Dashboard1?:language=en-US&:sid=&:redirect=auth&:display_count=n&:origin=viz_share_link).
